empty your thoughts, i'll organize them ─── ⋆

 modules
interactive matrix: click directly on any calendar day to quickly draft an event for that specific target date.

 whisper recognition: activate your local terminal mic with one tap to record your thoughts hands-free.

offline grace buffers: even if your backend server drops offline, local storage fallbacks keep your logged units safely saved in the browser!


🚀 boot sequence (how to run)
1. load dependencies
Bash
npm install
2. spin up the client

Bash
npx expo start
Press w to open the terminal view directly on your desktop web layout, or scan the screen QR code to load it on your phone!
